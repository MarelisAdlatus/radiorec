# Font Awesome Free icon fonts

The bundled `Font Awesome 6 Free-Regular-400.otf` and
`Font Awesome 6 Free-Solid-900.otf` files contain the copyright notice
`Copyright (c) Font Awesome` and identify their version as 6.0.0.
Their bytes have not been modified.

These font files are licensed under the SIL Open Font License 1.1,
independently of RadioRec's Apache 2.0 license. See the full
[OFL.txt](OFL.txt) and the upstream [LICENSE.txt](LICENSE.txt).
Both documents are bundled beside the fonts as application resources.

The upstream license overview is from
[Font Awesome 6.0.0](https://raw.githubusercontent.com/FortAwesome/Font-Awesome/6.0.0/LICENSE.txt).
The OFL text is from the
[official source](https://openfontlicense.org/documents/OFL.txt), with its
example copyright header replaced by the notice embedded in these fonts.
The license body is unchanged.

The fonts are loaded by `RadioRec.initFonts()` for icon glyphs used by
the main window and table renderers. Keep the font copyright and license
with any redistribution, including distributions containing the JAR.
